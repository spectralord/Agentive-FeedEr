Prototype v4 · Push-navigation Detail

Compact pushes into a tabbed Detail, not a filmstrip

Tap the card (or swipe right, away from the edge) to push into Detail — three real tabs, click to switch, Back returns to Compact. The skill badge jumps straight to the Skill tab.

Decided this round:
  • Compact → Detail is a push transition, not paging. Detail has 3 clickable tabs: Write-up, Context, Skill.
  • Context = related/similar sources (rare — most Reels have none) + caveat, together.
  • Write-up gets its own lightweight single-source reference above the text — separate from Context's fuller list.
  • One source by default. The Context tab's cluster is the exception, shown on the MCP Reel only.
  • Scores now flush to the true right edge.

Skill tab — first pass

Reuses the same seen/tried/mastered ring the actual /skills page has a TODO(UX pass) waiting for (gray/teal/gold) — same visual language in both places, not a separate invention.

Deliberately not a full copy of the node detail page: description, status, a couple of associated items, and one low-commitment quick action (only offered from "seen"). Anything deeper — notes, downgrading, the full Adoption Log — stays on the real Skill Map, reached via "Open in Skill Map."
