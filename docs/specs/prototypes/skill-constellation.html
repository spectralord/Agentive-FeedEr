Prototype · Skill Constellation + Knowledge Base

Fixed constellations, emergent stars

The 8 themes from src/lib/skills.ts are permanent regions, placed once. Skill nodes scatter deterministically inside their own region (position derived from the slug), so a new node from tonight's SkillTagger run appears as a new star without re-flowing anything you'd already learned to find. Click any node. Toggle knowledge decay to see the spaced-repetition idea.

Why this layout survives dynamic data

Nothing is force-directed. Theme centres are hand-placed constants. A node's position is hash(slug) → angle + radius inside its theme circle, with a few deterministic relaxation passes to stop overlaps. Same slug, same pixel, forever — so spatial memory works, and adding a node never moves an existing one.

Progress is luminosity, not points. The map literally gets brighter as you learn. No confetti, no score counter — the reward is that your own sky fills in. Mastered nodes are the only gold on the page, which is what keeps gold meaningful.

Decay dims, never demotes. With decay on, nodes fade by time-since-touched. You never lose a declared status — the star just wants re-lighting. "This could use a refresher" instead of "you lost progress."
